# Generalized Linear Models

Generalized Linear Models (GLMs) are a class of models that extend the linear regression model to allow for non-linear relationships between the input and output variables.

## What is a Generalized Linear Model?

A Generalized Linear Model (GLM) is a type of linear model that extends the linear regression model to allow for non-linear relationships between the input and output variables.
